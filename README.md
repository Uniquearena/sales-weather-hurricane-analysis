# Sales, Weather & Hurricane Analysis

A data visualization project exploring three different datasets — historical hurricane counts, city temperature comparisons, and retail sales data — using Python and Matplotlib.

## Dataset

- **Hurricanes.csv** — Yearly hurricane counts, visualized as a bar chart over time
- **CityTemps.csv** — Temperature comparisons between cities (e.g. San Francisco vs. Moscow), visualized as histograms
- **sample-salesv2.csv** — Retail sales transactions with customer names, prices, and dates, used to analyze customer purchase totals and trends

## Notebook

- **Assignment_Python8.ipynb** — Contains the data loading, cleaning, and a range of visualizations including:
  - Bar charts (hurricane frequency by year)
  - Histograms (city temperature distributions)
  - Grouped/aggregated sales analysis by customer
  - Line plots, scatter plots, and error bar charts demonstrating core Matplotlib plotting techniques

## How to Run

1. Clone this repository:
   ```
   git clone https://github.com/Uniquearena/sales-weather-hurricane-analysis.git
   ```
2. Open `Assignment_Python8.ipynb` in Jupyter Notebook or JupyterLab.
3. Make sure the CSV files are in the same folder as the notebook, then run the cells in order.

## Requirements

- Python 3.x
- pandas
- numpy
- matplotlib

## Key Skills Demonstrated

- Reading and cleaning CSV data with pandas
- Grouping and aggregating data by category
- Building multiple chart types with Matplotlib (bar, histogram, line, scatter, error bar)
- Customizing plot styling: labels, limits, ticks, colors, and figure size
